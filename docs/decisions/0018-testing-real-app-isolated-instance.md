# ADR 0018: Real-app testing only as an isolated instance, driven over CDP

Status: accepted
Date: 2026-11-23

## Context

The agent must test the real app without photographing the owner's desktop and without crossing the owner's running Rocksy.

## Decision

The app is driven through the WebView2 remote-debugging port (`tools/cdp.py`, `app/ui/tools/drive.py`: JS evaluation and page captures only, never desktop captures). A run with `ROCKSY_DATA_DIR` set is its own instance (no single-instance plugin); the single-instance plugin applies only to the normal profile. Synthetic vaults (generated by `tools/gen-vault.py`) are the references for measurements; the real vault is never touched. `add_vault` is free in an isolated instance (ADR 0011).

## Consequences

- A window opens and closes by itself during tests.
- What this cannot cover (second launch, native dialogs, drag and drop) is listed in `docs/status.md`.
- Runbook: `docs/runbooks/test.md`.
