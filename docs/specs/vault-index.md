# Spec: vault index (tags, links, search)

Status: normative
Last verified at: release 0.2.1 (branch kb-restructure; invariants taken from the contract and the tests as they stand, the test suite passed at 244 core and 124 UI tests)

## Scope

The per-vault index built by `build_tags`: tags with fragments, link graph with Obsidian-style resolution, full-text search; persistence and reconciliation. Command shapes and tag rules are in `app/CONTRACT.md` ("Vault index", "Search", "Links", "tags_list sorting and filtering", "Tag rules"). Rationale: `docs/decisions/0005-one-vault-index.md`, `docs/decisions/0006-change-detection-size-mtime.md`, `docs/decisions/0008-fulltext-search-tantivy.md`, `docs/decisions/0009-link-resolution-obsidian-style.md`, `docs/decisions/0014-panic-unwind-and-index-rebuild.md`.

| # | Invariant | Enforced by |

| VI-11 | Reconciliation detects changes by size and mtime only, re-reads only modified, added and renamed files, reads nothing when nothing changed | `reconcile_builds_then_reads_nothing_when_nothing_changed`, `reconcile_reads_only_modified_added_and_renamed_files`, `change_detection_uses_size_and_mtime_only` (`app/crates/rocksy-core/src/tags/persist_tests.rs`) |
